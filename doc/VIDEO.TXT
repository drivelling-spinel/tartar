By default Tartar supports rendering in three buffer formats,
which correspond to display resolutions in the following manner:
320x200          - 320x200
640x400          - 640x400 if possible, otherwise 640x480
1280x800         - 1280x1024
          
By selecting "extra" screen size option (rightmost screen side slider
position) players can relocate status bar below player view so that
it occupies part of the screen which is otherwise left empty
in 640x480 and 1280x1024.

Otherwise, in these resolutions player view with overlay HUD or status
bar is positioned in the center of the screen, with black
"horizontal pillars" above and below it.

In case when higher display resolution is desired but rendering
to smaller size buffer is preferred (due to, e.g. performance considerations
or for more "authentic" look), Scale to higher resolution menu item
offers the following options:

320x200  -   No    -  320x200  - 320x200
320x200  -   x2    -  640x400  - 640x400 if possible, otherwise 640x480
320x200  -   x4    - 1280x800  - 1280x1024
640x400  -   No    -  640x400  - 640x400 if possible, otherwise 640x480
640x400  -  x2,x4  - 1280x800  - 1280x1024 
1280x800 -   any   - 1280x800  - 1280x1024

Aspect ratio correction activated by setting Aspect ratio scale to 4:3
scales rendered buffer vertically more to fill the screen with it completely
in 640x480 resolution. In 1280x1024 resolution, this option makes
the picture of LCD displays more in line with how Doom looked on CRT
displays originally (i.e. less "squashed") but portion of the screen
still remains blank. Again, "extra" screen size can be selected to
relocate status bar covering the blank area.

Aspect ratio correction option has no effect in 320x200 and 640x400
display resolutions unless "widescreen" rendering imitation is also enabled.
With "widescreen" mode on, however, rendered raster will be scaled 
when in a level (or watching demo) and neither menu nor automap,
or help screens are active. This trait applies to all display resolutions.
